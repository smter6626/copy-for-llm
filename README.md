# Copy for LLM

一键把当前标签页整理成 Markdown 复制到剪贴板，粘贴给任意 LLM。全部本地处理，不联网。

## 安装

1. 打开 `chrome://extensions`，右上角打开「开发者模式」
2. 点「加载已解压的扩展程序」，选择这个 `copy-for-llm` 文件夹
3. 建议把图标固定到工具栏（拼图图标 → 图钉）

改了代码后，在扩展页点刷新按钮即可，不用刷新网页。

## 使用

| 操作 | 效果 |
|---|---|
| 点工具栏图标 / `Alt+Shift+C` | 自动识别：有选中文字 → 只复制选中；Discord / Slack → 对话；Canvas → 课程内容；其他 → 网页正文 |
| 右键 →「复制给 LLM」 | 强制选择模式：选中内容 / 网页正文 / 整页 / 仅表单字段 |

快捷键可在 `chrome://extensions/shortcuts` 修改。复制成功后页面右下角会提示字数和预估 tokens。

## 各模式说明

- **网页正文**：自动找 `<main>` / `<article>`，去掉导航、页脚、侧栏；保留标题、列表、表格、代码块、链接。页面上有 3 个以上表单字段时，末尾会附「表单字段」清单（含当前填写的值；密码不输出）。
- **Discord（discord.com）/ Slack（app.slack.com）**：输出「发送者 · 时间 + 内容」，包括回复引用、附件、表情回应、日期分隔线；Slack 打开线程面板时会分成两段。
- **Canvas（canvas.asu.edu 等）**：只取中间内容区，头部附课程路径（面包屑）。
- **整页**：不做任何过滤，用来兜底。

## 已知限制

- 只支持**网页版** Discord / Slack，桌面客户端里用不了。
- 聊天只能抓到**已经加载到页面上**的消息。想要更早的记录，先往上滚动，再点复制。
- `chrome://` 页面、Chrome 应用商店、跨域 iframe（比如 Canvas 的 New Quizzes、PDF 预览）抓不到。
- 网站改版可能导致适配失效。失效时会退回通用正文，提示里会显示「xx 适配未命中」。

## 反馈问题时请提供

- 是哪个网站的哪种页面（例如 Slack 线程、Canvas 讨论区）
- 复制出来的内容哪里不对（缺了什么 / 多了什么）
